# Smart Energy Theft Analyzer ⚡

A web-based **Smart Energy Theft Detection System** built using **Python, Flask, and Artificial Neural Networks (ANN)** to identify abnormal electricity consumption patterns and detect possible electricity theft.

The application allows users to upload smart meter data, preview the dataset, analyze consumption patterns, and predict whether the electricity usage is **Faithful (Normal)** or **Unfaithful (Possible Theft)** using a trained machine learning model.

---

## 🚀 Features

- **Web-Based Interface**: Simple and user-friendly Flask web application.
- **Dataset Upload**: Allows users to upload smart meter electricity consumption data.
- **Dataset Preview**: Displays uploaded data before performing prediction.
- **ANN-Based Prediction**: Uses an Artificial Neural Network trained with TensorFlow/Keras.
- **Electricity Theft Detection**: Classifies consumption patterns as **Faithful** or **Unfaithful**.
- **Data Preprocessing**: Uses `StandardScaler` for feature scaling.
- **Prediction Analysis**: Displays the prediction result based on the trained model.
- **Performance Analysis**: Provides model performance information for evaluating the detection system.
- **Interactive Interface**: Includes HTML, CSS, JavaScript, and Bootstrap for a responsive user experience.
